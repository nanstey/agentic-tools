# How-To / Guide Template

For accomplishing one task. Goal-oriented, ordered, verifiable.

```markdown
# <Task, phrased as an action>

<One sentence: what the reader achieves and when to use this.>

## Prerequisites

<What must exist first: access, installed tools, prior setup.>

## Steps

1. <Action.> <Command or code.>
2. <Action.> <Expected result so the reader can confirm progress.>
3. <Action.>

## Verify

<How the reader confirms success: a command output, a UI state, a test.>

## Troubleshooting

<Common failure and its fix. Omit if none.>

| Symptom | Cause | Fix |
| --- | --- | --- |
| <what they see> | <why> | <what to do> |
```

## Notes

- One task per guide. Split unrelated tasks into separate guides.
- Number steps in execution order; each step is one action.
- Give an expected result after key steps so the reader knows it worked.
- Use second person and imperative voice ("Run", "Open", "Set").
